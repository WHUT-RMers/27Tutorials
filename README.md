# 机器视觉入门

**学习入口只有一本：[机器视觉入门.ipynb](机器视觉入门.ipynb)。**

克隆培训仓库后，用 VS Code 打开 `02 机器视觉/lab` 文件夹，再打开这本 Notebook。从第 1 节配置环境开始，按顺序往下学习。使用 JupyterLab 时也打开同一个文件。

环境配置已合并为一节；图像处理、图片用途、操作步骤、练习和 PR 作业说明都在 Notebook 内。最后只交一次作业：三张对比图、三句说明、一个 PR。

```text
lab/
├── 机器视觉入门.ipynb       # 从环境准备到作业提交，全部在这里
├── display_tools.py         # 对比图排版工具，学习时无需打开
├── requirements.txt
├── assets/                 # 已提供的五张素材，无需逐个打开
├── outputs/                # 自动生成的练习结果与作业图片
└── submissions/            # 按 GitHub 用户名建立自己的作业目录
```

发布到 GitHub 的 Notebook 已保留示例输出；运行自己的环境时，请先选择 `.venv` 内核。
1. 翻转：使用了_硬币___图片，水平翻转后__左右位置对调了__。
2. 颜色调整：将__B或R__通道的偏移量设为__80，图像变得_变红发亮。
3. 滤波：使用了_中值_滤波，处理后__除去了黑白噪点，图像变得更平滑清晰。
